ساخت APK (رایگان، بدون نصب Android Studio)
1. در github.com یک حساب بسازید و یک مخزن (Repository) جدید ایجاد کنید.
2. همه فایل‌های این پوشه را در آن آپلود کنید (Add file > Upload files). پوشه مخفی .github/workflows و فایل build-apk.yml حتماً باید آپلود شود؛ اگر آپلود نشد، از Add file > Create new file با همین مسیر بسازید و محتوا را کپی کنید.
3. به تب Actions بروید، «Build APK» را انتخاب و Run workflow بزنید.
4. بعد از حدود ۵ دقیقه، از پایین صفحه اجرا فایل attendance-apk را دانلود کنید، از حالت zip خارج کنید و app-debug.apk را روی اندروید نصب کنید (اجازه نصب از منبع ناشناس لازم است).
